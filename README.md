# MAI Pulse v0.7 — группы, заявки и права доступа

Локальный учебный проект для **VS Code / Python / Flet / SQLite**. Это **не общий онлайн-сервер**. Регистрация и роли действуют только для одной локальной базы данных на данном компьютере.

## Главное в версии 0.7

- **Администратор** → «Модераторы» → у каждого слота появилась кнопка **«Удалить»** с подтверждением. Удаляется учётная запись и пароль, при этом уже опубликованные посты и фотографии **сохраняются**, чтобы не терять контент.
- **Новый студент** → «Зарегистрироваться как студент» на экране входа → после первого входа **обязательно вводит свою учебную группу**. Пока группа не указана, групповые разделы не открываются. Группу нельзя изменить самостоятельно после сохранения; администратор может исправить назначение в «Заявки на роли» → «Управление группами и ролями» → «Группа».
- Дедлайны, материалы, объявления, расписания и занятия **отделены по учебным группам**. Группа вводится текстом, например `М8О-101`. В разных группах могут быть разные ICS-ссылки.
- **Студент** может создавать личные задачи, отмечать их выполненными, делать собственные посты и добавлять материалы. Общие задачи старосты видны всей группе, но каждый студент отмечает их выполнение отдельно.
- **Староста** и **модератор группы** могут редактировать/удалять публикации группы, управлять общими заданиями, вручную добавлять и удалять занятия, изменять источник ICS. Эти полномочия **только внутри закреплённой группы**.
- **Модератор МАИ** по-прежнему работает только во вкладке «Весь МАИ», не видит закрытые групповые материалы.
- **Заявки на роли** — отдельная вкладка. Студент подаёт заявку на `Модератор МАИ` или `Староста` с комментарием. Администратор видит заявки, подтверждает или отклоняет. Пока заявка рассматривается, новую подать нельзя; после отклонения можно повторить.
- В том же разделе администратор может **исправить назначенную учебную группу** студента, а также **вручную назначить или снять** роли старосты/модератора группы любому студенту, у которого уже выбрана группа. Снятие роли возвращает обычные права студента без удаления учётной записи.
- При удалении поста по-прежнему требуется подтверждение. Загрузка фотографий в полный размер и загрузка файлов в «Материалы» сохранились.

## Разграничение прав

| Роль | Лента «Весь МАИ» | Своя группа | Управление ролями |
| --- | --- | --- | --- |
| Студент | Свои посты | Просмотр, свои посты/материалы и личные задачи | Подать заявку |
| Староста | Свои посты | Управление общими задачами, расписанием, групповыми публикациями | Подать заявку |
| Модератор группы | Свои посты | Управление общими задачами, расписанием, групповыми публикациями | Нет назначения ролей |
| Модератор МАИ | Модерация всех общих постов | Нет доступа к группе | Нет |
| Администратор | Полный доступ | Управление в выбранной группе | Полный доступ |

## Как установить поверх v0.6

1. **Закрой приложение.** Сделай копию папки проекта; обязательно отдельно сохрани `mai_pulse.db` и папку `mai_pulse_files` со всеми фото и материалами.
2. **Распакуй содержимое ZIP** в корень проекта рядом с `main.py`, заменив код, но **НЕ удаляя** `mai_pulse.db`, `mai_pulse_files` и `.venv`.
3. Открой папку MAI Pulse в Visual Studio Code, открой PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если виртуального окружения ещё нет:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

4. При первом входе администратор может выбрать группу для просмотра. Студенту приложение обязательно предложит указать номер группы. Для первой выбранной группы сохраняется привязка старых данных и прежнего ICS-календаря. Для **других групп** их староста/администратор задаёт **собственную ICS-ссылку** в «Настройках».
5. Проверь «Моя группа» → «Расписание», «Домашка», «Материалы». Затем открой «Заявки на роли» и «Модераторы» под администратором.

## Важные ограничения

- **Это локальная версия**, не общая сеть: публикации, пароли и документы других студентов не синхронизируются через интернет. Чтобы приложение работало одновременно на разных устройствах, нужны сервер и сетевая авторизация.
- Группа при первом входе **выбирается самостоятельно и не проверяется** по списку настоящих студентов. Для публичного MAI Pulse необходима проверка принадлежности к группе (приглашение или подтверждение старостой/админом). Не используй эту версию для конфиденциальных материалов.
- Любой человек с прямым доступом к файлу `mai_pulse.db` технически может изменить локальные данные независимо от ролей. Проверки ролей в приложении не заменяют серверные разрешения.
- Заявки и назначения ролей хранятся в SQLite. Письма/Telegram уведомления админу пока не отправляются.
- Испытаны автоматические сценарии БД, переходов ролей, разделения групп и миграции со схемы v0.6; графическое окно Flet на Windows необходимо проверить в твоём VS Code.

# MAI Pulse v0.6 · Роли и слоты модераторов

Настольное приложение для студентов, написанное на **Python + Flet**.

## Что нового: учётные записи и управление модераторами

Эта версия продолжает MAI Pulse 0.4 и добавляет **экран входа и подтверждение удаления постов**.

- **Первый запуск**: приложение предложит создать *первый аккаунт администратора*. Укажи логин, отображаемое имя и собственный пароль длиной **не менее 8 символов**. Готового пароля `admin/admin` нет.
- **Администратор**: видит все разделы, управляет постами в «Моя группа» и «Весь МАИ», может создавать студенческие аккаунты и отдельные **слоты модераторов**.
- **Модератор**: входит **с собственными логином и паролем**. В меню доступны только **«Весь МАИ»** и «Мой аккаунт». Можно публиковать, комментировать, ставить лайки и удалять чужие посты **только в общей ленте**. Нельзя удалять групповые объявления даже через прямой вызов операции базы с его учётной записью.
- **Студент**: может удалить только собственные посты в обоих разделах.
- Для всех разрешённых удалений появляется диалог **«Удалить публикацию?»** с кнопками «Отмена» и «Да, удалить». Фотография удаляется только после подтверждения.
- Панель администратора **«Модераторы»**: создать новый слот с отдельным паролем, посмотреть действующие слоты, сменить пароль, временно заблокировать и разблокировать слот.
- Пароли сохраняются **не открытым текстом**, а через PBKDF2-HMAC-SHA256 с индивидуальной случайной солью. Если пароль забыт, администратор задаёт новый; старый посмотреть нельзя.
- Существующие расписание из ICS, домашние задания, файлы и фотографии остаются на месте при обновлении (если не заменять `mai_pulse.db` и `mai_pulse_files`).

### Как создать модератора

1. Войди как администратор.
2. Открой слева **«Модераторы» → «Добавить слот»**.
3. Задай логин, имя и индивидуальный пароль (минимум 8 символов); запомни пароль и передай модератору отдельно.
4. Перейди в **«Мой аккаунт» → «Выйти из аккаунта»** и проверь вход под модератором.
5. Для блокировки или смены пароля снова войди администратором и открой «Модераторы».

### Важное ограничение безопасности

**Это всё ещё локальный прототип.** Учётные записи и проверки разрешений применяются внутри приложения, но владельцы компьютера/файла SQLite могут получить доступ к данным и менять их напрямую. Посты, загруженные материалы и пароли не синхронизируются между компьютерами. Для настоящего приложения, доступного всем студентам, нужны серверная авторизация, хранение данных на сервере, проверка разрешений при каждом запросе, HTTPS и аудит действий модераторов. **Не выкладывай `mai_pulse.db` и папку с материалами в общий доступ.**

## Что нового в v0.4 — фотографии без обрезки и новое окно публикации

- В ленте **«Весь МАИ»** изображения больше не обрезаются до формата 680×360. Показывается **вся фотография**, с сохранением пропорций. Для очень высоких изображений карточка ограничена по высоте, но изображение остаётся целым, с пустыми полями по сторонам.
- **Нажмите на фото** (или «Открыть оригинал») — откроется отдельный просмотр с исходными пикселями, приближением и перетаскиванием. Кнопка «Открыть файл» передаст оригинал системной программе просмотра Windows.
- Окно **«Новая публикация»** переработано: тёмная/светлая тема в стиле MAI Pulse, выразительный заголовок, поле текста, выбор категории, большая зона выбора фото, **предпросмотр перед публикацией**, замена и удаление выбранного фото, индикатор символов и аккуратные кнопки управления.
- Загружаемые файлы сохраняются **в исходном разрешении и качестве**, без пережатия; лимит фото остаётся 12 МБ.
- Для новой версии добавлены автоматические тесты размеров и пропорций изображений. Пользовательские данные из v0.3 не удаляются.

## Что было добавлено в v0.3

- **«Моя группа»** — отдельное пространство с внутренними вкладками «Обзор», «Расписание», «Домашка», «Объявления», «Посещаемость», «Материалы».
- **«Весь МАИ»** — отдельная лента в стиле студенческой соцсети: фото с подписями, категории, лайки, комментарии и удаление своих локальных публикаций.
- **«Материалы»** — теперь не только ссылки: можно **загружать настоящие файлы** PDF, DOCX, PPTX, XLSX, TXT, ZIP, изображения, Python и другие поддерживаемые форматы.
- **Сохранение между запусками**: база данных `mai_pulse.db`, а сами файлы — в `mai_pulse_files/photos` и `mai_pulse_files/materials`.
- **Безопасная миграция схемы**: существующие задания, импортированное расписание и старые материалы не стираются.
- Интерфейс остаётся в тёмной/светлой теме, с анимацией переходов и карточек.

> **Важное ограничение:** Лента «Весь МАИ» в этой версии является **локальным прототипом**. Другие студенты пока не увидят твои посты или фотографии. Для настоящего Instagram-подобного сервиса нужен сервер, онлайн-хранилище, аккаунты, модерация и права доступа. Не публикуй общую базу в интернете.

### Ограничения файлов

- Фото в постах: JPG, PNG, WEBP, GIF, максимум **12 МБ**.
- Материалы: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT, MD, CSV, ZIP, 7Z, PY, IPYNB и изображения, до **30 МБ** на файл.
- Файлы **копируются** в `mai_pulse_files/`, исходный документ можно переместить или удалить.
- «Открыть файл» использует программу, назначенную Windows по умолчанию.
- Для резервной копии и переноса нужны **оба компонента**: `mai_pulse.db` и папка `mai_pulse_files/`.
- Удаление загруженного материала или публикации удаляет соответствующий файл из управляемой папки.

## Быстрый старт на Windows в VS Code

1. Сделайте **копию текущего `main.py`, `mai_pulse.db` и `mai_pulse_files/` (если есть)**, если они у вас уже есть.
2. Распакуйте **содержимое** архива в вашу папку `D:\vscodes\MAI-Pulse`.
   Файлы `main.py`, `requirements.txt`, папки `core`, `ui`, `tests` должны находиться рядом.
3. Откройте папку проекта в VS Code, затем терминал PowerShell.
4. Используйте **существующее виртуальное окружение**, если оно уже создано:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py
   ```

   Если окружения нет, создайте его:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py
   ```

   Либо дважды нажмите `start.bat`, он проверит окружение и запустит программу.

## Расписание группы — уже подключено

В приложении **уже прописана** ICS-ссылка вашей группы:

```
https://schedule.devcosmos.ru/api/calendar/group/68ad7b8442fd77a64d5fd70d1c41225c.ics?download=1
```

- При **первом запуске** приложение автоматически скачивает календарь с сайта и сохраняет занятия в SQLite.
- При последующих запусках оно проверяет наличие обновлений **раз в календарный день**.
- Для немедленного обновления откройте **«Расписание» → «Обновить ICS»** или
  **«Настройки» → «Синхронизировать расписание»**.
- При успешной загрузке настоящие пары заменяют демонстрационные; **добавленные вручную пары не удаляются**.
- Ссылку можно изменить в настройках, если понадобится другая группа.

Импорт берёт занятия за последние 45 дней и следующие 185 дней, в том числе повторяющиеся.
Для первой загрузки необходим интернет. Если интернет недоступен или календарный сервис не отвечает,
приложение не подставляет выдуманные пары вместо реальных, а ранее скачанные данные остаются в базе.
После восстановления соединения нажмите «Обновить ICS» или перезапустите программу.

**Примечание:** расписание скачивается **при запуске**, а не по таймеру, пока приложение непрерывно открыто.

## Куда сохраняются данные

Файл `mai_pulse.db` автоматически создаётся рядом с `main.py`. Это обычная SQLite-база.
Программа автоматически расширяет схему старого дедлайнера и публикаций без удаления предыдущих записей.
Для переноса всех данных закрой программу и скопируй **`mai_pulse.db` вместе с `mai_pulse_files/`**.
В базе в том числе хранится ICS-ссылка — **не публикуйте свою личную базу на GitHub**.

При первом запуске создаются несколько **демонстрационных** заданий, материалов и групповых постов; примерные занятия при включённом ICS-календаре удаляются автоматически.
Их можно удалить через «Настройки → Убрать демоданные»; ваши реальные записи не будут удалены.

## Технические детали

- Целевая среда: Windows 10/11, Python 3.11+, актуальная стабильная Flet 1.0.x.
- Оконный интерфейс рассчитан прежде всего на десктоп (минимальная ширина около 960px).
- Анимация переключения вкладок сделана через `AnimatedSwitcher`, реакции карточек — `animate`.
- Код не отправляет твои локальные задания и личные заметки сторонним сервисам.
  При импорте расписания приложение делает HTTPS-запрос по указанной тобой ссылке.

## Если что-то не запускается

- `ModuleNotFoundError: flet`: запусти установку зависимостей через интерпретатор из `.venv`.
- `py не распознан`: используй `python` (у тебя Python 3.11.9).
- Ошибка синхронизации: проверь адрес ICS и доступность сервиса в браузере.
- Перед заменой старых файлов **обязательно сохрани копию `mai_pulse.db`**.
